# CorpSkill official skills

Agent skills built by [CorpSkill](https://corpskill.app), packaged as one Claude Code plugin per industry.

## Install in Claude Code

```
/plugin marketplace add littlerobben10-hue/corpskill-skills
/plugin install real-estate@corpskill
```

Available plugins: `real-estate`, `careers`, `private-equity`, `investment-banking`, `finance-operations`, `asset-management`, `banking`, `wealth-management`, `equity-research`.

## Use elsewhere

Each skill is a folder with a `SKILL.md`. Copy `plugins/<plugin>/skills/<skill>/` into `~/.claude/skills/`, or download the zip from the skill's page on corpskill.app and upload it in Claude.ai.
